# Deploying the AI Auto Continue privacy page

Upload the contents of:

`privacy-site/ai-auto-continue/privacy/`

to the matching path on `www.oppanda.com` so the final page is available at:

`https://www.oppanda.com/ai-auto-continue/privacy/`

The folder contains a standalone `index.html` with inline CSS and no JavaScript, analytics, cookies, external fonts or external assets.

After deployment:

1. Open the URL in an incognito window.
2. Confirm HTTPS is valid and there is no login requirement.
3. Check the page on desktop and mobile.
4. Enter the exact URL in the Chrome Web Store Developer Dashboard privacy-policy field.
