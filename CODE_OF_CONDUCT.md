# Code of Conduct

AI Auto Continue aims to maintain a professional, technically focused contributor community.

## Expected behavior

- Be respectful and specific when discussing code, design, bugs, and review feedback.
- Critique implementations and evidence, not people.
- Protect user privacy: redact conversations, account details, tokens, cookies, and other sensitive data.
- Respect third-party licenses, trademarks, and platform rules.
- Disclose security-sensitive findings privately before public discussion.

## Unacceptable behavior

Harassment, personal attacks, discriminatory conduct, deliberate privacy violations, credential sharing, malicious code submissions, or attempts to use the project to bypass platform safeguards are not acceptable.

## Reporting

For community or security concerns, use the project support page:

https://www.oppanda.com/ai-auto-continue/support/

Security vulnerabilities should not be posted as public issues before coordinated disclosure.
