## Store listing checklist

- Disclose the publisher link in the detailed description.
- Keep the promotion visibly labeled in the extension UI.
- Do not describe the link as required for operation.
- Do not add affiliate parameters without a separate policy review.
- Do not inject the promotion into third-party AI websites.

## Language-aware prompts

Auto mode detects the language of the latest completed AI reply locally immediately before the first prompt send and selects a matching continuation prompt. Users may instead select a fixed language or enter a custom prompt. Conversation text used for language detection is not uploaded or stored.

## AI service safeguards

AI Auto Continue does not bypass account requirements, CAPTCHAs, rate limits, usage quotas, safety controls or other protective measures of supported AI services. When such a state is detected, automation pauses.


## Per-run authorization

Before automation starts, the popup shows the current AI website, the continuation prompt behavior and the maximum number of automatic prompt messages. The user must click Start to authorize that content and recipient for the current run. The extension pauses when the user types, submits manually, changes conversation or encounters an ambiguous state.
