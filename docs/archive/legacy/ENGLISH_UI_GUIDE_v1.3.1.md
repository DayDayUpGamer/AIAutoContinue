# AI Auto Continue v1.3.1 — English UI and Screenshot Guide

## Switch the extension interface to English

1. Open a supported AI website such as ChatGPT.
2. Click the AI Auto Continue toolbar icon.
3. Click the gear icon in the upper-right corner.
4. Under **Interface**, set **Interface language** to **English**.
5. The settings page reloads automatically.
6. Return to the AI tab and open the Popup again.

The setting is stored locally. It controls only Popup and Options text. Automatic continuation-message language remains controlled separately under **Continuation message → Language**.

## Capture the Popup

### Fast method

- Windows: press `Win + Shift + S`.
- macOS: press `Shift + Command + 4`.
- Select only the Popup area.

### Exact Popup screenshot with Chrome DevTools

1. Open the Popup on a supported AI page.
2. Right-click inside the Popup and choose **Inspect**.
3. In the Popup DevTools window, press `Ctrl + Shift + P` on Windows/Linux or `Command + Shift + P` on macOS.
4. Run **Capture screenshot**.

For Chrome Web Store screenshots, place the real Popup capture on a 1280 × 800 canvas that shows the supported AI-page context. Do not stretch the Popup or show controls that are not present in the submitted build.
