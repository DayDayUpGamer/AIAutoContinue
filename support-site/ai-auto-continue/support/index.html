Quick start

  1. Open a normal conversation on a supported AI website.
  2. Click the AI Auto Continue toolbar icon.
  3. Choose the number of follow-ups.
  4. Click Start. The extension runs only in the current tab.
Safety behavior: automation pauses when you type, send manually, change conversations, encounter verification, or reach a service limit.

Common issues

“This website is not supported” appears
This is expected when the active tab is not one of the AI websites explicitly supported by this project. Return to the AI conversation tab and reopen the extension. Login pages, browser pages such as chrome://extensions, and third-party mirror sites are not supported.
The extension does not send the next message
Wait for the AI reply to finish, confirm the current tab is still the same conversation, and check whether the website shows a login, CAPTCHA, rate-limit, quota, or verification message. Refresh the AI page, reopen the extension, and start a new run.
Automation pauses after I type or press Enter
This is intentional. Manual editing or sending takes priority over automation. Reopen the Popup and start again when you are ready.
How do I switch the extension interface to English?
Open the Popup, select the gear icon, then set Interface language to English. Interface language is separate from the language used for follow-up messages.
The AI website changed its layout
Update the extension to the newest Chrome Web Store version. If the issue remains, report the website, extension version, Chrome version, operating system, and reproduction steps. Do not send private conversation content.
How do I reset settings?
Open the extension settings and restore the desired values, or remove and reinstall the extension. Uninstalling clears extension-local settings. It does not delete data from the AI website.

Privacy and safety

  • Conversation content is processed locally and is not sent to Oppanda.
  • The extension does not use analytics, telemetry, or remote executable code.
  • It does not bypass login, CAPTCHA, rate limits, quotas, or AI safety protections.
  • Settings are stored in browser-local extension storage.

快速开始

  1. 在受支持的 AI 网站打开普通对话页面。
  2. 点击 Chrome 工具栏中的 AI Auto Continue 图标。
  3. 选择自动续接次数。
  4. 点击“开始”。插件只在当前标签页运行。
安全机制：当你手动输入、手动发送、切换对话、遇到验证页面或达到服务限制时，自动化会暂停。

常见问题

出现“当前网站暂不支持”
当当前标签页不是官方支持的 AI 网站时，这是正常提示。请返回 AI 对话标签页后重新打开插件。登录页、chrome://extensions 等浏览器内部页面以及第三方镜像站不受支持。
插件没有发送下一条消息
请等待 AI 回答完成，确认当前仍是同一个对话，并检查页面是否出现登录、验证码、速率限制、配额或验证提示。可以刷新 AI 页面，重新打开插件并启动新一轮任务。
手动输入或按 Enter 后插件暂停
这是预期的安全行为。用户的手动编辑和发送优先于自动化。准备好后重新打开 Popup 并再次启动。
如何把插件界面切换为英文？
打开 Popup，点击右上角齿轮，将“界面语言”设置为 English。界面语言与自动续接消息的语言互相独立。
AI 网站改版后插件失效
先更新到 Chrome Web Store 最新版本。如果仍有问题，请反馈网站、扩展版本、Chrome 版本、操作系统和复现步骤。请不要发送私人对话内容。
如何重置设置？
可以在插件设置页重新配置，或卸载后重新安装。卸载会清除插件本地设置，但不会删除 AI 网站中的任何数据。
